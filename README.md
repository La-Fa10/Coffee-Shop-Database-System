Coffee Shop Database Management System
About

A database management system designed to organize and manage coffee shop information, including customers, employees, products, and orders. The project uses SQL to store, retrieve, and manage data efficiently.

Features
Store and manage customer information.
Manage employee details and job positions.
Store product information, prices, and quantities.
Record customer orders and payment methods.
Link orders with customers, employees, and products.
Generate order reports using SQL views.
Retrieve and analyze data using queries, joins, and subqueries.
Calculate total sales, average order value, and total orders.
